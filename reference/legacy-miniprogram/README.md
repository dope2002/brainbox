# 奇有此理｜旧小程序原型

> 每一滑，都有意想不到的小挑战。

这是一个 **可以直接导入微信开发者工具的原生微信小程序 MVP**，另附可在电脑/手机浏览器中打开的纯 HTML 演示版本。

## 1. 运行方式

### 微信小程序（推荐）

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择 **导入项目**，项目目录指向本文件夹 `brain-blindbox/`（不是 `pages/`）。
3. 项目类型选择 **小程序**，非微信小游戏。项目配置默认使用 `touristappid` 方便在工具内查看；如果开发者工具要求 AppID，请改为你自己的小程序 AppID 或工具允许的测试 ID。
4. 点击 **编译**，在模拟器里直接点选作答，上下滑动切换题目。
5. 真机调试、微信内预览、分享等功能可能需要真实 AppID 和相应开发者权限。

项目不需要后端、不需要配置数据库、不需要安装 npm 包。

### 直接看浏览器原型（最快）

打开 `web-demo/index.html`，手机和电脑都可以操作。电脑上使用下一题按钮或键盘 `↓` 切题；手机浏览器可以向上滑动切题。也可以在该目录启动静态服务器：

```bash
cd web-demo
python -m http.server 8080
```

然后访问 `http://localhost:8080`。手机访问时使用同一局域网下电脑的 IP 地址。

## 4. 内容数据结构

```json
{
  "id": "q001",
  "type": "choice",
  "category": "人文历史",
  "title": "李白和杜甫，谁的年龄更大？",
  "subtitle": "选出你认为正确的答案",
  "options": ["李白", "杜甫", "同岁", "无法确定"],
  "answer": 0,
  "explanation": "李白约生于701年，杜甫生于712年，李白年长约11岁。",
  "difficulty": "轻松"
}
```

`type` 支持 `choice`（四选一）、`visual`（16 格找不同）、`sequence`（按顺序点选）。所有题型共用基础元信息，可以将本地 `questions.js` 替换为 Java/Spring Boot API。

## 5. 推荐与埋点设计

- 推荐策略初版通过题目分类轮换、避免短时间重复、基于本机完答/收藏偏好做简单随机抽取，不引入机器学习模型。
- 每次进入新题记录 `question_viewed`，作答记录 `question_answered`，未作答离开记录 `question_skipped`，其他包括收藏、取消收藏、分享、反馈。
- 小程序本地缓存键：`brainbox_state_v1` 和 `brainbox_events_v1`。同一设备清理小程序数据会丢失这些记录。
- 为避免收集身份信息，首版不采集微信 openid、手机号、地理位置；发布前仍应按实际功能准备隐私告知。

## 6. 测试

安装 Node.js 后运行：

```bash
node tests/test-engine.js
node tests/test-page.js
```

这两项验证题库字段、答案合法性、内容排重、基础页面事件。**模拟测试不能替代微信开发者工具编译和真机测试。**

## 7. 下一阶段建议

**先测试体验，不急着接后端。** 让10～20个不同年龄的人直接体验原型，记录首次会刷多少道题、哪类题被跳过、哪类题被分享/收藏。根据结果再补到 300～500 道高质量题，并选择合适的首批互动题模板。

下阶段技术架构建议：微信小程序 → Spring Boot REST API → PostgreSQL（题目/版本/曝光事件）→ 简单规则推荐，数据量起来后再做在线推荐和内容审核平台。

注意：所有题目均为演示素材，正式上线前需要对事实、歧义、难度、图形和版权进行复核。
