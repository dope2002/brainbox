# 旧原型迁移记录

| 来源 | 可复用部分 | 迁移决定 |
|---|---|---|
| `data/questions.json` | 64 道演示题，八类各 8 道，含 51 道选择、8 道找不同、5 道排序 | 保留旧 ID 作为迁移关联，选择、视觉、排序分别映射到 `single_choice`、`odd_one_out`、`sequence`。将原选项或格子的索引一次性转换为稳定 ID，排序答案同步转换。中文类别和难度映射为主规格枚举。源题需逐题复核后再决定上架。 |
| `utils/engine.js` | 纯函数判题、可注入随机源、近邻排重思路 | 阶段 0 用稳定选项 ID 判定。旧推荐只按类别计权重，阶段 3 按规格增加题型、难度、探索配额和稳定分组。 |
| `pages/index/` | 一屏一题、回看已答、手势及结果反馈的行为参考 | 新小游戏以 Canvas 渲染并由独立输入模块处理手势。旧 WXML、WXSS、`Page()` 和 `setData()` 留在参考目录。 |
| 旧本地事件 | 可参考收藏、分享和作答入口 | 旧曝光按进卡计数，缺少有效可见时长、离线回传和服务端归因。阶段 2 按主规格 §5 编写状态机和上报协议。 |
| `tests/` | 旧结构、判题及模拟页面断言 | 保留旧基线，小游戏另走自己的入口和平台模拟测试。 |

阶段 0 使用可演算的自编选择题验证画布与交互，题目状态均为草稿。正式发布题库从独立的内容审核流程导入。
